개인정보처리방침

적용 도구: G-ware Calender Sync
운영자: NEOARTNET
시행일: 2026년 11월 13일

1. 처리 목적

사용자가 선택한 그룹웨어 일정을 본인의 Google 캘린더에 추가·수정하여 확인할 수 있도록 합니다.

2. 처리하는 정보

  • 그룹웨어에서 내보낸 일정 제목, 설명, 장소, 시작·종료 일시, 반복·제외 규칙, 고유번호
  • 사용자가 입력한 달력 다운로드 링크
  • Google OAuth 접근·갱신 토큰과 클라이언트 설정
  • 앱이 생성한 Google 캘린더의 식별정보 및 일정 변경 확인용 해시
  • 실행 시각, 처리 건수, 성공 여부, 제한된 오류 메시지 등의 실행 기록

일정 제목과 설명에는 이름 등 개인정보가 포함될 수 있습니다. 사용자는 전송할 달력과 일정 내용을 사전에 확인해야 합니다. 프로그램은 Google 비밀번호를 수집하지 않습니다.

3. Google 데이터 접근 및 사용

사용자의 OAuth 승인으로 앱이 생성한 보조 캘린더를 생성·조회·관리하고 해당 캘린더의 일정을 추가·수정합니다. 기본 캘린더 등 앱이 생성하지 않은 캘린더를 관리하기 위한 권한은 요청하지 않습니다. 이 도구의 Google API로부터 수신한 정보의 사용 및 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

4. 저장 위치와 전송 대상

다운로드 링크, OAuth 설정·토큰, 캘린더 연결 정보, 실행 기록은 사용자의 Windows PC에 저장합니다. 확인용 프로그램으로 다운로드한 ICS 파일도 PC에 남을 수 있습니다. 동기화 대상 일정은 Google Calendar API를 통해 사용자의 Google 계정으로 전송·저장됩니다. Google의 데이터 처리는 Google 개인정보처리방침의 적용을 받습니다.

이 정적 웹사이트는 일정이나 인증 파일을 받는 기능을 제공하지 않습니다. 웹사이트 호스팅 과정의 접속정보 처리는 GitHub 개인정보처리방침의 적용을 받을 수 있습니다.

5. 공유 및 이용 제한

도구는 데이터를 광고, 판매, 신용평가 또는 범용 AI 모델 학습에 이용하지 않습니다. 사용자 지정 Google 계정으로의 일정 전송 이외에 별도의 분석 서버로 일정을 전송하는 기능은 없습니다. Google 캘린더의 공유 범위는 사용자의 계정 설정에 따라 달라지므로 사용자가 확인해야 합니다.

6. 보관 및 삭제

PC의 설정·인증 파일과 기록, Google에 저장된 일정은 사용자가 삭제할 때까지 남을 수 있습니다. 원본에서 일정이 삭제되어도 현재 도구는 Google 일정을 자동 삭제하지 않습니다.

  1. Windows 작업 스케줄러에서 동기화 작업을 사용 안 함으로 설정하거나 삭제합니다.
  2. Google 계정의 연결 관리에서 앱 접근 권한을 해제합니다.
  3. Google 캘린더 설정에서 앱이 생성한 전용 캘린더를 삭제합니다.
  4. PC의 인증·설정 파일, 다운로드한 ICS, 로그 및 보관한 인증 백업을 삭제합니다.

토큰 파일만 삭제하는 것은 Google 측 권한 해제나 Google 일정 삭제를 대신하지 않습니다.

7. 보호 조치

인증정보는 로컬 파일로 저장되므로 PC 사용자 계정과 파일 접근 권한으로 보호해야 합니다. 사용자는 인증 파일과 달력 링크를 공개 저장소나 게시판에 게시하지 않아야 합니다. 통신에는 HTTPS를 사용합니다.

8. 문의와 변경

GitHub 문의 게시판을 통해 문의할 수 있습니다. 공개 게시판에 개인정보나 인증정보를 기재하지 마세요. 처리 방식 변경 시 이 페이지의 내용과 업데이트 날짜를 변경합니다.
