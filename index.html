G-ware Calender Sync

개인 Windows PC에서 실행하는 그룹웨어 일정 → Google 캘린더 단방향 동기화 도구입니다. 본 페이지는 도구의 기능과 데이터 처리 방식을 설명하며, 일정 조회나 Google 로그인을 제공하지 않습니다.

주요 기능

  • 사용자가 접근 권한을 가진 그룹웨어 달력의 ICS 내보내기 파일 다운로드
  • 사용자가 지정한 Google 계정에 전용 캘린더 생성
  • 일정 고유번호를 기준으로 새 일정 추가 및 변경 사항 수정
  • Windows 작업 스케줄러를 이용한 하루 한 번 실행

사용 범위와 제한

개인 사용자를 위한 도구이며 회사의 공식 서비스가 아닙니다. 회사가 허용한 데이터 전송 범위에서 사용해야 합니다. Google에서 수정한 내용은 그룹웨어로 전송하지 않으며, 현재 버전은 원본에서 삭제한 일정을 자동 삭제하지 않습니다.

Google 권한

Google Calendar API의 calendar.app.created 권한으로 앱이 생성한 보조 캘린더와 그 일정을 관리합니다. Google 비밀번호를 프로그램에 입력하거나 저장하지 않습니다.

데이터 처리

프로그램은 실행 PC에서 그룹웨어 일정과 Google API를 처리합니다. 이 공개 웹사이트에 업무 일정이나 인증정보를 업로드하지 않습니다.
